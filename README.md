# BringUpBoard2Zephyr

A [Cursor](https://cursor.com) skill generated with cursor-agent to help add new board support for [Zephyr RTOS](https://zephyrproject.org/).

## Goal

Make bringing up Zephyr on different boards as approachable as ESP32 is for electronics hobbyists and makers—lower the bar so more boards can run Zephyr without deep RTOS expertise.

## Share your success

If you get a board working with Zephyr using this skill, please share your story. When a board is confirmed working, add it to [`boards/list.md`](boards/list.md) so others can find it.

## Upstream submissions

If you want to contribute board support to the Zephyr project, follow the [Zephyr community contribution guidelines](https://docs.zephyrproject.org/latest/contribute/index.html).

Before you submit:

- Understand the code and what it implies for the tree and maintainers
- Verify that the board actually works
- Submit only board support you intend to use

New board code has a real maintenance cost. Prefer contributions you will stand behind.
